# Textos de consentimiento

Esta carpeta guarda los textos de consentimiento versionados (`v1.md`, `v2.md`, …)
que redacta la asociación, con su asesoría legal. Ingeniería no escribe ni
aprueba el contenido legal.

- `consentimiento.version_texto` guarda el nombre del archivo vigente cuando se
  otorgó el consentimiento (por ejemplo `v1`). Cada texto nuevo es un archivo
  nuevo; los anteriores no se editan ni se borran, porque cada consentimiento
  registrado remite a la versión que la persona aceptó.
- La app registra el consentimiento como dato (quién lo otorgó, relación con el
  atleta, medio, fecha y versión del texto), pero no entrega texto legal.
- No hay textos reales en el repositorio hasta que la asociación los entregue.
  El `v1` usado en los tests es solo una etiqueta de prueba.
